# Dungeon-Crawler-I
This is a simple test of a dungeon crawler. Use the arrow keys to move and the space bar to do the attack animation (it currently does not have a hitbox). If you click the left-shift key, you will toggle debug mode where your hitbox turns off. If your health drops to zero or below, you will dies and the scene will reset. Click start game to start. The settings menu currently does not do anything. Thanks to 0-lobster for the sprites and tilemap, you can find their page here: https://o-lobster.itch.io/.

The link to play the game: https://chilywilly.itch.io/dungeon-crawler-i-wip
